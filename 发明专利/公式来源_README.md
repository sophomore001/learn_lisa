# 公式来源文件说明

本文件夹保存了当前《公式算法说明》里引用到的论文来源文件。

可直接使用的完整 PDF：

1. `Haney_2001_Design_Technique_for_Analog_Temperature_Compensation_of_Crystal_Oscillators_FULL.pdf`
   来源：Virginia Tech 学位论文 PDF

2. `Wang_2020_A_Method_to_Increase_the_Frequency_Stability_of_a_TCXO_by_Compensating_Thermal_Hysteresis.pdf`
   来源：公开可访问 PDF

3. `Haapala_2020_Temperature_Compensation_of_Crystal_References_in_NB-IoT_Modems.pdf`
   来源：作者主页公开 PDF

4. `Schoukens_2019_Nonlinear_System_Identification_A_User-Oriented_Roadmap.pdf`
   来源：arXiv 公开 PDF

目前未找到公开全文 PDF，仅保存来源页面：

5. `Kusters_1991_Hysteresis_in_Quartz_Resonators_A_Review_PubMed.html`
   说明：当前仅下载到 PubMed 摘要页面，便于保留出处链。

注意：

1. `Haney_2001_Design_Technique_for_Analog_Temperature_Compensation_of_Crystal_Oscillators.pdf` 是先前下载残留的损坏副本，不建议使用。
2. 请优先使用文件名带 `_FULL.pdf` 的 Haney 完整版。
3. 若在专利文件中说明“四参数联合参数估计”的主参考来源，优先引用 `Schoukens_2019_Nonlinear_System_Identification_A_User-Oriented_Roadmap.pdf`；若说明“静态多项式系数可通过最小二乘或 OLS 估计”，可再辅引 `Haapala_2020_Temperature_Compensation_of_Crystal_References_in_NB-IoT_Modems.pdf`。
