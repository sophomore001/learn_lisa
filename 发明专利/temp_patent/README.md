# temp_patent Workspace

This folder is the dedicated working set for branch `codex/temp_patent`.

Contents:

- `docs/`: patent-facing reports and archived source documents for this branch
- `code/`: compensation and identification scripts used by the report
- `output/`: generated figures and summary files
- `refs/`: lightweight reference notes for the sources used in the new supplement

Working rule for this branch:

- historical temperature + synchronous frequency data are used for offline identification
- real-time temperature + previous model state are used for online compensation
- formula interpretation and code implementation are kept consistent in this folder
