# 202602191048 一种基于热惯性模型的超稳晶振动态温度补偿方法历史温度与参数辨识补充报告

## 一、适用范围
本补充报告仅针对本申请说明书中的步骤 S4、步骤 S5 以及公式（1）至公式（4）进行说明，重点回答以下问题：历史温度数据与实时温度数据在本申请中的作用分工、四个参数的反演路径、参数估计流程为何采用“先初始化、再联合精修”、训练数据如何组织，以及如何说明所估参数具有物理合理性和工程可实现性。

## 二、历史温度数据与实时温度数据的作用分工
根据本申请的技术方案，历史温度数据不是用来替代实时温度数据，而是主要用于离线辨识阶段；实时温度数据则用于在线补偿阶段。更准确地说，历史温度数据必须与同步采集的原始频率数据一一对应，用于在步骤 S4 中估计三阶静态温度系数 `alpha`、`beta`、`gamma` 和热时间常数 `tau_th`；步骤 S5 中则将已经辨识完成的参数代入模型，利用实时采集的温度序列递推计算当前动态温度频偏，再对原始频率输出进行修正。

文献直接支撑如下：Wang 等人在 Sensors 2020 的论文中指出，传统 TCXO 补偿通常只基于当前温度，而热滞后补偿需要同时考虑当前温度信息和温度变化历史信息；当温度变化较快时，温度传感器与晶体之间还会出现 thermal lag。IEEE Std 1193-2022 则明确区分了静态温度敏感度与动态温度敏感度，并指出在未达到热平衡前，测量结果会依赖刺激的时间轮廓和被测对象的初始状态。

基于上述文献并结合本申请采用的一阶热惯性递推结构，可以得到本申请更稳妥的表述：历史温度数据与历史频率数据用于模型参数标定；实时温度数据与上一时刻动态状态量用于在线补偿。也就是说，在线补偿并不重新训练参数，但由于热惯性模型属于有记忆的动态系统，其递推过程天然保留一个短时历史记忆。

## 三、四个参数的反演方式
本申请的四个待估参数为三阶静态温度系数 `alpha`、`beta`、`gamma` 和热时间常数 `tau_th`。这四个参数不是分别对单条公式逐一求逆得到，而是通过公式（1）至公式（3）构成一个统一的前向灰箱模型后，再利用温度输入和频率输出数据进行联合反演。

对于本申请，前向模型可写为：
`x_t = alpha*DeltaT_t + 0.5*beta*(DeltaT_t)^2 + (1/6)*gamma*(DeltaT_t)^3`
`y_t = a*y_(t-1) + (1-a)*x_t`
`a = exp(-Delta t/tau_th)`

其中，公式（1）给出静态温度频偏，公式（2）和公式（3）将其转化为包含热惯性记忆的动态温度频偏；式（4）仅用于根据动态温度频偏生成补偿后输出：
`f_c(t) = f_m(t) - y_t`

因此，严格参与参数反演的是公式（1）至公式（3），公式（4）只是输出修正式，不应作为参数反演方程本体。

文献直接支撑如下：IEEE Std 1193-2022 明确指出，环境敏感度可以通过曲线拟合和最小二乘分析获得，并且多项式拟合通常建立在相应物理模型基础上；Haapala 等人在 IEEE TCAS-I 2020 的论文中指出，多项式温补模型系数可通过 ordinary least squares estimation 重新计算；Schoukens 与 Ljung 的综述则表明，非线性动态系统辨识的核心是利用输入输出数据去估计具有已知结构的模型参数。若仅针对本申请中的四参数联合估计选择一篇主参考文献，则更适合采用 Schoukens 与 Ljung 的《Nonlinear System Identification: A User-Oriented Roadmap》，因为该文与本申请“已知公式结构、未知参数、由输入输出数据反演参数”的方式最为一致，而 Haapala 2020 更适合作为静态多项式系数可通过 OLS 估计的辅助参考。

基于上述文献并结合本申请公式结构，可以将本申请中的参数辨识定义为：以公式（1）至公式（3）构成的前向灰箱模型为对象，以实测频率与模型输出频率之间的残差平方和最小为目标，采用非线性最小二乘法联合估计参数向量 `[alpha, beta, gamma, tau_th]`。

## 四、为什么采用“先初始化、再联合精修”
若直接对四个参数进行全盲联合拟合，静态系数与时间常数之间容易出现参数代偿，即数学上可以逼近测量数据，但得到的参数未必具有稳定的物理解释。特别是当温度轨迹中缺乏明显动态激励时，`beta`、`gamma` 与 `tau_th` 的耦合会更强。

IEEE Std 1193-2022 明确指出，环境敏感度测量会受到非线性、不同时间常数、瞬态效应、滞后和老化的影响；其 Annex A 进一步给出一个关键操作原则，即在计算静态温度敏感度前，应先测得热时间常数，并剔除多个 `1/e` 时间常数内的非平衡数据。Deng 等人在 2021 年关于石英晶体谐振器频温特性的论文中指出，传统研究通常将频率-温度特性描绘为三次函数，但单独使用该静态曲线难以准确描述热滞后。

基于上述文献，本申请更适合采用以下估计流程：
1. 先在准稳态温区估计 `alpha`、`beta`、`gamma` 的初值。这里的“准稳态温区”是指温度变化速率较小、热不平衡效应较弱的样本段，此时静态三次模型可以更稳定地刻画频温骨架关系。
2. 再利用温度斜坡段、阶跃段或热循环段估计 `tau_th` 的初值。因为热时间常数本质上反映的是动态响应速度，不能仅靠静态温区样本可靠获得。
3. 最后将四个参数放入统一目标函数中，用非线性最小二乘法做联合精修。此时前两步提供了更合理的初值，有助于提高收敛稳定性和参数可解释性。

上述“先分步初始化，再联合精修”属于结合文献与本申请模型结构作出的工程实施建议，但它与 IEEE 1193 关于热时间常数、非平衡数据剔除和动态温度敏感度测量的原则是相一致的。

## 五、训练数据应具备的组成
为提高四个参数的可辨识性，步骤 S4 所用历史数据不宜仅包含单一平缓升温片段，而应尽量包括以下三类数据：
- 恒温驻留段或低温变速段，用于提取准稳态频率点，支撑静态三次系数的估计；
- 升温与降温斜坡段，用于暴露同一温度点在不同热历史下的频率差异，体现热滞后与热惯性；
- 温度阶跃段或较快热循环段，用于估计时间常数并验证模型对动态响应的描述能力。

IEEE Std 1193-2022 Annex A 还给出一条对本申请很有用的判据：当温度引起的频移小于测量噪声时，可先进行频率-温度相关分析，以判断温度敏感性是否统计显著，再进入参数拟合阶段。该原则意味着：在噪声较强的训练条件下，本申请优选先做温频相关性与动态激励充分性的粗筛，再进行联合拟合。

## 六、如何说明估计参数是可信的
对于审查口径，仅说明“算法收敛”通常不足以证明参数可信。更稳妥的说明应包含以下三个层面。

第一，参数量级应与公开高稳晶体振荡器或 USXO 的温度稳定度量级相符。Galliou 与 Mourey 关于 ultra stable quartz oscillator 的论文指出，目标是在 `-30 °C` 到 `+70 °C` 范围内将相对频率变化控制在 few `times 10^-10` 的量级。这意味着本申请拟合得到的一阶温度灵敏度不应明显偏离高稳石英器件通常可接受的数量级。

第二，拟合所得的频温曲线形状应符合石英晶体振荡器的已知特征。Deng 等人的论文指出，石英晶体谐振器的频率-温度静态特性通常可用三次函数建模；Wang 等人的论文表明，同一温度循环下的升温曲线与降温曲线并不完全重合。因此，若本申请估计得到的静态项呈合理三次形状，且动态项能解释升降温路径差异，则该参数组合具有更强的物理可解释性。

第三，补偿结果应在统计意义上表现出稳定改善。IEEE Std 1193-2022 强调应区分确定性环境变化与随机频率波动，并提醒避免将低频确定性漂移误判为随机不稳定度。因此，本申请中可以通过以下现象共同证明参数可用：补偿后温频相关性下降、频率-温度回滞环收缩、中长积分时间上的 Allan 偏差改善，以及在不同数据段重复辨识时参数波动较小。

## 七、建议写入交底书的正式表述
可将本申请的相关说明整理为如下表述：

本发明中，历史温度数据与同步采集的原始频率数据主要用于离线训练阶段的模型参数辨识；实时温度数据则在在线运行阶段作为模型输入，用于递推计算当前动态温度频偏并实时修正输出频率。由于热惯性模型属于有记忆的动态系统，在线补偿虽然不再重新估计参数，但仍需保留上一时刻的动态状态量，从而体现短时历史信息。

本发明中的四个参数并非对各单独公式分别求逆，而是将静态温度多项式模型与一阶热惯性递推模型组合为统一的前向灰箱模型，以实测频率与模型输出频率之间的残差平方和最小为目标，采用非线性最小二乘法联合估计得到。其中，公式（1）至公式（3）构成参数反演主体，公式（4）为在线补偿输出公式。

为提高参数可辨识性，优选先利用准稳态温区数据获得静态温度系数初值，再利用温度阶跃、斜坡或热循环数据获得热时间常数初值，最后进行全参数联合优化。参数可行性优选通过参数量级、频温曲线形状以及补偿后统计指标改善情况进行综合验证。
